# スクリーンショット置き場

`docs/index.html` が下のファイル名で読み込みます。置いていないファイルの枠はページに出ません。
ホーム画面だけは、画像が無い間は HTML で作った見本が代わりに出ます。

今ある画像はエミュレータ（Android 16、1080×2400）でダミーの4回線を入れて撮り、幅 720px に縮めたものです。通知は上半分、ウィジェットはホーム画面の上部だけを切り出しています。

| ファイル名 | 画面 | 写したいもの |
|---|---|---|
| `home.png` | ホーム（回線一覧） | 3回線のカード、残日数バッジ、進捗バー。残り5日くらいの回線が赤になっているもの |
| `notification.png` | 通知 | 「【povo】解約まであと◯日」の通知（通知シェードを下ろした状態） |
| `widget.png` | ホーム画面のウィジェット | ウィジェットを置いたホーム画面 |
| `purchase.png` | トッピング購入記録シート | トッピングの一覧が開いた状態 |
| `detail.png` | 回線の詳細 | 自動解約日、購入履歴、カレンダー登録ボタン |
| `settings.png` | 設定 | 通知タイミング、通知時刻、解約までの日数 |

- 本物の電話番号が写らないように、ダミーの回線（090-0000-0001 など）で撮ってください
- 縦向き、PNG か WebP。幅 720px 前後に縮めておくとページが軽くなります
- 縦横比が 1080×2400 と違う場合は、`index.html` の `<img>` の `width` / `height` を合わせて直してください
