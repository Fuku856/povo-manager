povoの自動解約日を数えるアプリ

最後にトッピングを買った日から180日。povo Manager は回線ごとに残り日数を出して、期限が近づいたら通知します。Androidで使えます。

APKをダウンロード

無料。Android 8.0 以降で使えます。

あと25日

自動解約日 2026年11月9日（月）

日付を変えると、その場で計算し直します。アプリでは、これを回線の数だけ並べて毎日数え直します。

povo は基本料0円のまま回線を置いておけるので、サブ回線やデータ専用に2本、3本と増やしがちです。ただ、180日トッピングを買わずにいると解約されることがあります。

1回線ならカレンダーに書いておけば足ります。2回線、3回線になると、どの番号でいつ何を買ったかを覚えていられません。それで、数える係をアプリにしました。

メインあと160日090-0000-0001
サブあと25日090-0000-0002
データ専用あと5日090-0000-0003

回線をまとめて一覧に

電話番号と、最後にトッピングを買った日を入れるだけです。ホーム画面に回線がカードで並び、残り日数の少ない順にひと目でわかります。表示名とメモは自由に付けられます。

残り日数でバッジと進捗バーの色が変わります。

  • 31日以上
  • 30日以内
  • 14日以内
  • 7日以内と期限切れ

期限の前に通知が届く

初期設定では、自動解約日の30日前、14日前、7日前、3日前、前日、当日に通知します。期限を過ぎても回線を消すまでは毎日知らせます。通知する時刻は0時から23時のあいだで選べます。

povo Manager 【povo】解約まであと7日: サブ 2026/11/09までにトッピングの購入が必要です。
  1. 30日前
  2. 14日前
  3. 7日前
  4. 3日前
  5. 前日
  6. 当日

回線ごとに変えられる

メイン回線は30日前から、捨ててもいい回線は前日だけ、のように回線ごとに通知の日を上書きできます。

トッピングの期限も

データ追加などのトッピングにも有効期限があります。こちらは初期設定で3日前と前日に知らせます。

データ専用あと5日

  • サブ25日
  • 仕事用61日
  • メイン160日

アプリを開かずに確かめる

ホーム画面のウィジェットに、期限がいちばん近い回線を大きく、ほかの回線を最大4つまで小さく出します。残り7日以内の回線は赤い文字になります。ウィジェットに出す回線と順番は設定で選べます。

買ったら記録する

トッピングを買ったら、回線を開いて購入日を記録します。よく使うトッピングは一覧から選べて、有効期限も自動で入ります。一覧にないものは名前を手で入れてください。

そのほかにできること

カレンダーに登録
回線の画面から、自動解約日を Android のカレンダーアプリに予定として入れられます。
バックアップ
回線と購入履歴をJSONファイルに書き出せます。読み込むときは、今のデータに足すか、全部入れ替えるかを選べます。
解約した回線をしまう
もう使わない回線はアーカイブに移せます。一覧からは消えて、記録は残ります。
180日を変える
povo の規約が変わったときのために、解約までの日数を1日から3650日のあいだで変えられます。

インストール

APKをダウンロード

無料。Android 8.0 以降で使えます。

  1. Android のスマートフォンで、このページの「APKをダウンロード」を押します。
  2. ダウンロードしたファイルを開きます。「この提供元のアプリを許可」と出たら、ブラウザに許可を出してください。
  3. 「インストール」を押して、終わったらアプリを開きます。最初に通知の許可を求められるので、許可してください。

Google Play ストアでは配布していません。ファイルは GitHub の Releases に置いてあり、GitHub Actions がソースコードからビルドしたものです。新しい版が出たら、同じ手順で上書きインストールすればデータはそのまま残ります。

よくある質問

povoの180日ルールとは？

povo 2.0 では、180日間有料トッピングを買わず、同じ期間の通話やSMSなどの従量料金の合計が660円を超えない場合、利用停止や契約解除になることがあるとされています。

条件は変わることがあるので、正確なところは povo の公式サイトで確認してください。

通話料が660円を超えている月もありますが、日付は合っていますか？

povo Manager はトッピングを買った日だけで数えていて、通話やSMSの料金は見ていません。そのため表示される自動解約日は、実際より早いことはあっても、遅いことはありません。

電話番号などのデータはどこに保存されますか？

スマートフォンの中だけです。povo Manager はインターネット接続の権限を持っていないので、登録した電話番号やメモが外に送られることはありません。機種変更のときはJSONファイルに書き出して移してください。

iPhone版はありますか？

ありません。Android 8.0 以降のスマートフォンで使えます。

povoの公式アプリですか？

違います。個人が作っている非公式のアプリで、povo や KDDI とは関係ありません。不具合や要望は GitHub の Issues に書いてもらえると助かります。
